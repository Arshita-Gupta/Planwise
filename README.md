# Planwise

Planwise is a simple student planner web application that helps students organize tasks, manage subjects, and keep track of deadlines.

## Features

- Dashboard with task statistics
- Today's Focus
- Task progress tracking
- Add, edit and delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks by:
    - All
    - Today
    - Upcoming
    - Overdue
    - Completed
- Filter tasks by subject and status
- Sort tasks by priority, due date and recently added
- High, Medium and Low priority levels
- Upcoming deadlines
- Add and manage subjects
- Confirmation before deleting tasks or subjects
- Prevents deleting subjects that still have assigned tasks
- Responsive layout

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

No backend or database is required for the current version.
